# ТЗ на генерацию картинок для карточек

Нужно создать ассоциативные изображения для слов узбекского словаря. Цель: ученик должен вспоминать значение по картинке без чтения перевода.

## Общий стиль

- Формат: квадрат 1024x1024 PNG.
- Стиль: чистая современная 3D/пластилиновая или мягкая векторная иллюстрация, без фотореализма.
- Фон: светлый теплый фон `#F7F6F1`, без текста.
- Композиция: один главный объект или понятная бытовая сцена в центре.
- Цвета: естественные, не кислотные; зеленый `#10A66A` можно использовать как фирменный акцент.
- Без букв, слов, цифр и водяных знаков внутри изображения.
- Изображения должны хорошо читаться в размере 300x225 внутри карточки.
- Для глаголов показывать действие: человек выполняет действие, но без сложной сцены.
- Для местоимений использовать простые композиции с людьми и направлением внимания.
- Для вопросительных слов использовать сцену вопроса, но не рисовать большой знак вопроса как единственный объект.
- Для числительных показывать количество предметов, но не писать цифры.
- Для прилагательных и наречий показывать контрастный визуальный образ.

## Шаблон промпта

```text
Create a square 1024x1024 educational flashcard illustration for the Uzbek word "{uz}" meaning "{ru}".
Style: clean soft 3D clay/vector illustration, warm off-white background, centered subject, friendly but not childish, no text, no letters, no numbers, no watermark.
Make the meaning visually obvious for a beginner language learner. Use one clear object or simple everyday scene.
```

## Как использовать в приложении

1. Сгенерировать PNG для каждого слова.
2. Сохранить в `public/word-images/{word.id}.png`.
3. Добавить в данные слова поле `image: "/word-images/{word.id}.png"` или заменить текущий `visual`.
4. В карточке показывать изображение, а текущую SVG-заглушку оставить как fallback.

## Приоритет генерации

1. Сначала существительные и глаголы.
2. Затем вопросительные слова и числительные.
3. Затем местоимения.
4. Затем прилагательные, наречия и фразы.
